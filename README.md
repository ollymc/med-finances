# Med Finances

Simulateur financier destiné aux médecins libéraux français, avec un premier module métier consacré à la neurologie et à la comparaison de trajectoires hospitalo-libérales.

## Versions archivées

- v2.0 — prototype du simulateur neurologique
- v2.1 — moteur de comparaison et projections patrimoniales
- v2.2 — accueil public, comptes utilisateurs et authentification
- v2.3 — correction du traitement hospitalier à l’échelon 5
- v2.4 — ancienneté, échelon, astreintes partagées et fiscalité familiale

Les archives de déploiement Docker seront conservées dans le dossier `releases/`.

> Les paramètres fiscaux, sociaux, hospitaliers et tarifaires doivent rester configurables et être vérifiés lors de chaque changement réglementaire.
